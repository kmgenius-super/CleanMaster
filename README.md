# CleanMaster - PC 안전 디스크 정리 도구

Windows 환경에서 누적된 불필요한 캐시, 임시 파일, 업데이트 잔여 패키지 등을 선별하여 안전하게 정리하는 네이티브 데스크톱 GUI 애플리케이션입니다.

## ✨ 주요 기능

- **실시간 C: 드라이브 상태 표시**: 드라이브 전체 용량, 사용량, 남은 공간 시각화
- **항목별 선별 정리**:
  - **NVIDIA DirectX 셰이더 캐시 (DXCache)**: 수십 GB 누적 가능한 구버전 셰이더 캐시 정리 (필요 시 자동 재생성)
  - **NVIDIA App 업데이트 잔여 패키지 (ota-artifacts)**: 수 GB에 달하는 업데이트 압축 파일 정리
  - **NVIDIA 드라이버 다운로더 패키지**: 다운로드 완료된 드라이버 설치 파일 정리
  - **DirectX 3D 디스플레이 캐시 (D3DSCache)**: 디스플레이 셰이더 캐시 정리
  - **Windows 사용자 임시 파일 (Temp)**: 만료된 사용자 임시 파일 정리 (사용 중인 파일은 안전하게 보존)
  - **시스템 오류 크래시 덤프**: 비정상 종료 시 기록된 덤프 파일 정리
  - **개발 도구 캐시 (NPM & Pip)**: 패키지 관리자의 임시 다운로드 캐시 정리
  - **Windows 휴지통**: 휴지통 비우기
  - **웹 브라우저 임시 캐시 (Chrome / Edge / Whale)**: 웹 이미지 캐시 정리 (로그인 정보, 쿠키, 북마크 완벽 보존)
- **철저한 안전 설계**:
  - 코드 레벨에서 개인 데이터 폴더(바탕화면, 내 문서, 사진 등) 및 윈도우 시스템 핵심 폴더 접근 차단
  - 실행 중이거나 잠긴 파일은 강제 삭제하지 않고 안전하게 건너뜀

## 🚀 실행 방법

### 요구 사항
- Python 3.10 이상
- `customtkinter` 라이브러리:
  ```bash
  pip install customtkinter
  ```

### 실행
```bash
python app_gui.py
```
또는 `run.bat` 파일을 더블 클릭하여 실행할 수 있습니다.
